# Vendored licence texts

Canonical copies of licences whose text is **verbatim by requirement**. The
GPL family forbids modifying the licence text, so one shared copy is the same
text every project ships.

They exist because fetching a licence from upstream is not always possible:
a host may rate-limit (eduke32's does), or the source repository may be gone
(sacdextractgui) or taken down (shiru).

This shortcut does **not** apply to MIT, BSD, ISC or similar. Those embed a
per-project copyright line, so only the project's own file is correct.
